# Time Admin

## Purpose and users
Administrators need to understand team attendance, inspect an individual day, decide leave requests, maintain NFC fobs, and configure working hours. Daily oversight is frequent; enrollment and settings are occasional setup tasks.

## Information and action priorities
- Team: selected date/range, who is included, worked time, live presence, and flagged days. Keep date navigation adjacent to the working grid. Name/cell selection opens the existing day editor.
- Leaves: requester, dates, hours, current balance and over-balance warning precede Approve/Reject. Review notes need persistent visible labels. Past decisions remain reachable alongside editable balances.
- NFC: explain the select → capture → bind sequence, distinguish verification from enrollment, and keep reassign/retire beside the relevant fob.
- Settings: group activation, business day, automatic tagging windows, and reminders. Keep the save action visible and make the timezone limitation understandable to an administrator.
- Day editor: fully readable time blocks and exact time fields are the primary editing path. A Timeline view remains available for spatial comparison. A block's tag, note, times, and IN/OUT status must be visible without relying on tiny calendar rectangles.

## Layout and visual treatment
Shared cool-white/graphite semantic tokens, cobalt selection, restrained translucent toolbar surfaces, opaque data surfaces. Labeled filter groups distinguish the displayed range from live presence filtering. Responsive overview cells, full-width actionable leave cards, discrete settings sections and a calm NFC setup panel create task-specific hierarchy. Long names and notes wrap; dense comparative tables scroll only within their own container.

## Preserved contracts
No mutation, fetch, permission, formula, presence, accrual or boundary changes. saveTimeBlock remains the only existing day-edit write sequence. Raw interval identities are preserved in the new list view. All source categories remain selectable and action gating stays intact. Radix retains modal focus management; motion respects reduced-motion.
